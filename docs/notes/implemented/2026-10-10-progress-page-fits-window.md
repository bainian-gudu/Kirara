# 进度页在固定窗口内收敛

Status: implemented

## Problem

安装、更新与卸载共用同一个窗口，客户区大小由宿主写死并按系统文本缩放与 DPI 取整。进度页要同时容纳步骤表、阶段状态、总体统计与活动文件列表；四步竖排的步骤表加列表比 520×250 客户区的可用高度多出 70 到 130 像素。主容器按内容长高时，左栏插画随行高重新适配、右下角取消按钮被推出可视区，进度条压住列表最后一行，看起来像窗口在安装过程中被撑大又恢复。

## Decision

窗口客户区是 520×280，再乘系统文本缩放与 DPI 取整；尺寸只在 `native/host/mod.rs` 定义一处。安装器、更新器与卸载器共用这份宿主代码，卸载器还是安装器映像的副本，三者尺寸必然一致。

主容器 `.main` 与 `.content` 固定为视口高度并 `overflow: hidden`，窗口高度不随内容变化；`.content` 是横向 flex 行，左栏插画在固定列宽内按 `object-fit: contain` 等比缩放。

进度块 `.progress` 占满 `.right` 的剩余高度，步骤表、阶段状态与总体统计固定不动，只有活动文件列表在剩余高度里滚动，列表不再有 128px 上限。列表的下边距是 28px，等于浮动取消按钮高出列表底边的部分（按钮高 32 + 距底 12 − 列表距底 16），列表区域整体落在按钮上方，任何一行都不会被按钮遮挡。`.progress` 自身保留 `overflow-y: auto` 兜底：固定部分自己就装不下时整块滚动，而不是裁掉内容。

两处滚动区都不显示滚动条（`scrollbar-width: none` 与 `::-webkit-scrollbar { display: none }`），内容超出时用滚轮查看。

步骤表横向排列并允许换行（12.5px 字号、14px 图标）。四步竖排占 116px，横排占 50px，省下的高度留给文件列表。

## Alternatives considered

- 保持 520×250，只让整个进度块滚动：总体统计会随列表滚走，与[安装过程信息展示对齐](../proposed/2026-09-21-progress-information-parity.md)的验收条件「总体统计不随列表滚走」冲突。
- 加高到 300 以上以容纳竖排步骤表：确认页内容只到 194.7px，多出的高度成为空白，左栏插画在更高的列里显得更小。
- 安装期间隐藏产品描述行：省下 32.8px，但确认页与进度页之间会出现内容跳动，长描述下也不够用。
- 保留列表的 128px 上限：窗口变矮时它会先占满再溢出，把溢出推给外层。

## Verification

测量条件：`dist/index.html` 由 rsbuild 1.5.10 production 构建产出，在 chrome-headless-shell 155.0.8059.39 中以 520×280 与 650×350 两个视口加载；WebView2 宿主桥与 i18n 表按 `web/__tests__/setup.ts` 的同一份合并表以脚本注入，界面状态经 `ui-state` 事件推送。

| 判据 | 结果 |
| --- | --- |
| 主容器高度恒等于视口，不随进度内容变化 | PASS：确认页、进度页、完成页、失败页与弹窗各夹具下 `document.documentElement.scrollHeight` 与 `.content` 高度都等于视口高度；未收敛前同一条件下量到 271（step 2）与 380.7（step 3 + 12 个文件） |
| 左栏插画不被拉伸，取消按钮与进度条始终在窗口内 | PASS：插画容器恒为 168×226；取消按钮 236..268、进度条 276..280，滚动前后位置不变 |
| 总体统计与阶段状态不随列表滚走 | PASS：12 个活动文件时列表滚动量 189px，`.progress` 自身滚动量为 0，统计、按钮与进度条位置不变 |
| 列表区域不与浮动取消按钮重叠 | PASS：列表矩形 170.7..236，按钮 236..268，两者相邻且不相交（520×280） |
| 常见状态无需滚动 | PASS：step 2 + 2 个文件与 step 3 + 3 个文件滚动量均为 0，文件名与各自计数完整可见 |
| 内容超出时可滚动查看且不出现滚动条 | PASS：12 个活动文件时列表滚动 189px，滚到底后最后一行位于取消按钮上方；`.active-files` 的 `offsetWidth - clientWidth` 为 0，滚动条不占宽度 |

## Consequences

- 520×280 下活动文件列表可见 3 行；并发下载上限是 16 个文件，更多活动项靠列表内滚动查看。
- 进度页的取消按钮比确认页的安装按钮矮（32px 对 40px），为列表让出右下角。
- 真实 WebView2 的滚动条宽度、系统文本缩放下的步骤表换行与 DPI 取整仍需在目标机器上确认；本机证据来自 headless Chromium。
